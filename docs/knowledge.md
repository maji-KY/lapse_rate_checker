## 1. 計算方法

- **到達高度（パーセル法）**: 地上2m気温の空気塊を乾燥断熱減率 0.98℃/100m で持ち上げ、周りの気温を下回る高さ。周りの気温は Open-Meteo の気圧面（975〜700hPa）の気温とジオポテンシャル高度で、面の間は直線で補間する。
- **雲底**: 地上の標高 + 125m ×（気温 − 露点）。雲底が乾燥の頂より低ければ、雲底を到達高度とする（積雲の日は雲底が上限）。
- **層ごとの減率**: 隣り合う面の気温差 ÷ 高度差 × 100。地上2m → 最下層の面は「地表層」として評価から外す。meteoblue も地上約200mまでの不安定は表示しない。
- 地上の標高は Open-Meteo が返す値（足尾の地点で約297m）。それより低い面（1000hPa ≈ 216m など）は地面の下なので捨てる。

## 2. 減率の区分（℃/100m）

| 区分       | 範囲     | 根拠                                                                               |
| ---------- | -------- | ---------------------------------------------------------------------------------- |
| 逆転       | <0       | 定義                                                                               |
| 弱い・蓋   | 0〜0.5   | DHV info 174: 0.5未満は上昇が弱く、次のサーマルまでの間隔が長い                    |
| 弱め       | 0.5〜0.7 | DHV info 180（二次情報）: 0.5〜0.7 は弱め、雲底に届くことは少ない                  |
| 良い       | 0.7〜0.9 | DHV info 174: 0.5〜0.8 はきれいにまとまり使いやすい。DHV info 180: 0.7〜0.9 は良好 |
| 強い・荒れ | ≥0.9     | DHV info 174: 0.9以上は強く速いが、小さくちぎれて荒れ、センタリングが難しい        |

- DHV info 174 は原文で確認済み。180 は検索要約経由で原文は未確認。
- 上空が冷たい春や、北寄りの寒気が入る日は減率が大きくなる（DHV info 174）。
- 層平均の減率が小さくても、実際のサーマルは上がることがある（meteoblue）。区分は目安。

## 3. 到達高度の区分（標高）

| 区分   | 範囲        | 根拠                                                                                                  |
| ------ | ----------- | ----------------------------------------------------------------------------------------------------- |
| 渋い   | <800m       | 足尾山の山頂 約628m から +170m 程度。推論                                                             |
| 粘れる | 800〜1100m  | nasa 日記の 900〜1000m の日（2022-01-02、01-10、01-31）                                               |
| 良い   | 1100〜1500m | 冬の好条件日 1200〜1500m（日記）。XC には周りの地面から約1000m以上の対流層が必要（Technical Soaring） |
| 強い   | ≥1500m      | 春の XC の日（2022-03 の 120km、2025-04 の 160km など）は予報の頂が 1900m 超                          |

- 「800m 以上に届く時間帯」の 800m も同じ考え方（`usableTopM`）。
- 日記に「1700mギリギリまで」という表現があり、エリアに高度の上限がある可能性がある。表示の上端を 1700m にしているのはそのため。

## 4. 上乗せ温度を +0℃ にした理由

- nasa 日記の高度付き10日（2022年1〜3月）と GFS の過去予報を比べると、+0℃ の頂（970〜1300m）が日記の高度（900〜1500m）とほぼ一致し、+2℃ は約300m 高すぎた。+2℃ はほとんどの日で上限近くまで行き、日ごとの差が見えなくなる。
- 米国気象局のソアリング予報手法（TA 88-23）は、予報最高気温から上乗せなしで乾燥断熱線を引く。
- フランス FFVL の約11万フライト × ERA5 の研究（2026年の査読前論文）: 平地の到達高度は約1100m AGL。冬はサーマルの上昇が機体の沈下率に近く、実際の到達高度は理論上の頂より低い。
- Hindman ほか: グライダーの実際の到達高度は、予報の対流層の頂より 431〜673m 低い。
- Allen (2006) NASA のサーマルモデル: 平均上昇は頂の1/4の高さで最大、頂の9割を超えると下降になる。頂付近は使いにくい。
- 結果として、+0℃ の頂は「上手いパイロットが届く最高高度」に相当する。全員が届く高さではない。

## 5. データの制約

- **MSM**: 気圧面は約11km 格子・3時間ごと（毎時の値は補間）、約3日先まで。地上の値は約5km 格子・1時間ごと。毎時の到達高度の変化は、主に地上気温の変化から来る。
- **GSM・ECMWF**: 気圧面が 1000/925/850/700hPa しかなく、200〜1700m を2層にしか分けられない。そのため4日目以降は「傾向」とし、毎時の表は出さない。
- **GFS**: 25hPa ごとに面があるが、日本付近の精度は未検証。
- **過去予報**: MSM の気圧面は 2025-12-11 以降しか残っていない。それより前は GFS（2022年〜）で比べる（2025年12月の重なりで MSM との相関 0.95）。
- **サーマルの強さ（W\*）**: 地表の顕熱フラックスと境界層の高さが必要で、JMA のデータには無いため出していない。

## 6. 外れやすいパターン

- **山の効果**: 日射を受けた斜面のサーマルは、平野の格子で計算した頂より高く上がることがある（Oberson、RASP 解説）。数値の根拠はない。
- **雲ひとつない快晴**: 高気圧の沈降で混合層が浅く、頂が低いところで頭打ちになりやすい。
- **薄い逆転層**: 面の間隔が 200〜500m あるので、それより薄い逆転は見逃す。
- **2m 気温のずれ**: 予報の最高気温が低すぎると到達高度も低く出る。山の尾根は低め、谷は高めにずれやすい。
- **反例**: 2022-01-30 は予報の減率 1.05 と良い値だったが、日記は「高くは上がらない」だった。
- **海風**: 夕方の海風による上昇は含まない。
